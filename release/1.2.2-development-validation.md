# 1.2.2 development and publication validation

Date: 2026-10-10. Source baseline: `b3189636dccb678d923c5c697464ff98bb9099fa`.

## Change

Version 1.2.2 publishes the bounded task review and digest-bound evidence reads
validated in [the defect report](1.2.1-abort-response-fix-validation.md).
The package version, lockfile root, installer version constant, current command
examples and version-dependent test expectations advance from 1.2.1 to 1.2.2.
Historical release records retain their original versions. Android/Gradle
templates, execution rules and approval checks remain unchanged.

## Validation

The underlying fix passed the complete 330-test suite with no failures,
cancellations or skips before this metadata update. The 1.2.2 candidate passed
65 release-specific tests covering documentation, metadata, upgrade, installation
doctor, configuration merging, package contents and initialization. Typecheck
and build passed. Initial sandbox verification hit `ps EPERM`; the same tests
passed outside the sandbox with authorization.

All 229 package files match candidate bytes and modes. Compared with the already
verified fix tarball, only ten packaged files differ: package metadata, current
documentation and the installer version constant in JavaScript and declarations.
The two compiled-file changes consist solely of 1.2.1 becoming 1.2.2.
The first pack attempt hit sandbox npm-cache permissions and was rerun with
authorization. Isolated tarball installation, package version, CLI help, plugin/API
imports, installer pinning, bounded status and exact evidence reconstruction
all passed. An initial smoke script incorrectly called a nonexistent CLI
`version` command; it was corrected to inspect the installed package metadata.
No implementation change was needed. This release record is excluded from the
npm package.
