# 1.3.1 development validation

Date: 2026-10-12. Status: targeted development validation complete; not published.

This patch aligns Planner with the generated V7 affected Debug policy and prevents
silent full-verification fallback in new capable-project drafts. The optional
fallback reason is digest-bound and visible in approval text; old approvals keep
their original authority. Package metadata, lockfile and installer references are
all 1.3.1.

Queue CLI, OpenCode list and task details use a read-only runtime projection. It
checks live process identity, task/workspace/run binding and timestamps, rejects
malformed and terminal observations, and keeps the original recorded state.
Executor and Shell writes carry run IDs, including on resumed executions.
