## Delivered behavior

- Queue-owned OpenCode shell commands may claim a task when they remain
  descendants of the active Worker but run in a separate process group.
- Queue ownership still requires the active queue key and run id to match, and
  the caller must either share the Worker's process group or be a proven
  descendant of the Worker's PID.
- An unrelated process cannot claim a task merely by copying the active run id.
