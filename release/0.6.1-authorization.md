## Verified upgrade sequence

An existing installation must first run doctor with its exact installed
version, then upgrade with the target version, then run the target doctor. The
verified `0.6.0` to `0.6.1` sequence is:

```sh
npx @frankzhang2026/opencode-android-orchestrator@0.6.0 doctor . --json
npx @frankzhang2026/opencode-android-orchestrator@0.6.1 upgrade . --json
npx @frankzhang2026/opencode-android-orchestrator@0.6.1 doctor . --json
```

The first upgrade attempt in the disposable clone ran in a restricted executor
that denied normal OpenCode user-database access. Shadow verification failed
closed and the transaction restored the complete `0.6.0` installation. The
same exact upgrade under normal user-data access succeeded without cleanup
warnings. The resulting configuration retained the installed module scope and
Gradle matrix and added `longCommandTimeoutMs: 1800000`.
