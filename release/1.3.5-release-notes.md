# 1.3.5 release notes

Status: source release prepared; npm publication has not been performed.

Fix installation and upgrade failures introduced in 1.3.4: the transaction
self-test now copies status.cjs into its temporary project. Previously the
18th check failed with MODULE_NOT_FOUND, causing upgrade rollback. A new Node
regression executes all 46 transaction checks with the shipped templates.

Managed-file and original-backup integrity checks remain enforced. Switching
Git branches does not switch the ignored installation manifest; inconsistent
local installations still require verified recovery before upgrade.

## Validation

- Candidate 1.3.5-rc.1: new regression reproduced the missing-helper failure
  before the fix and passed all 46 transaction checks afterward.
- Candidate affected regression suite: 66 passed, no failures or skips.
- An isolated real WordPress checkout with a verified 1.3.3 installation
  reproduced the published 1.3.4 upgrade failure and exact rollback.
- The same checkout upgraded successfully using the frozen candidate; doctor,
  transaction tests, shadow run, all 55 managed file hashes, and actual OpenCode
  plugin entry/config-hook loading passed.
- Promotion to 1.3.5 changes version metadata and documentation only. Build,
  41 release/documentation/upgrade/installation tests, and npm pack dry-run pass.
- No business task or Android application build/test was run for this
  installation-specific repair. The user's original WordPress checkout was
  left unchanged.
