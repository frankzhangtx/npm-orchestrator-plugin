## Delivered behavior

- `android_orchestrator_snapshot` action `snapshot` now returns only `sourceRoot`, `targetBranch`, and the fixed `planningHead`.
- New bounded `list` pages provide path discovery at that exact commit, with prefix/query filters, stable bound cursors, sensitive-file exclusion, and a 16 KiB response ceiling.
- New bounded `readChunk` pages preserve exact UTF-8 content, including trailing whitespace, while binding cursors to the commit and path. The legacy `read` action remains for known-small files.
- Planner agent and Orchestrator skill instructions now follow `snapshot` -> `list` -> `readChunk`, preventing large repositories from truncating the planning metadata.
